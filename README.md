# ORBIT — Autonomous Space Systems

> High-end, futuristic, cinematic landing page for next-generation autonomous aerospace technology.

## ?? Tech Stack
- **React 18**
- **Vite**
- **Three.js** & **React Three Fiber** (`@react-three/fiber`, `@react-three/drei`)
- **GSAP** & **ScrollTrigger**
- **Lucide React**
- **Pure Custom CSS** with Design Tokens (No Tailwind / No Bootstrap / No UI libraries)

## ?? Features
1. **Loading Screen**: Futuristic system initialization sequence (00 ? 100%) with status readout.
2. **Hero Section**: 3D procedural spacecraft & starfield with mouse parallax and cinematic entrance.
3. **Intro Typography**: Staggered scroll-triggered text reveal (*"SPACE IS NO LONGER THE LIMIT"*).
4. **Technology Section**: System architecture cards with interactive hover effects and technical telemetry.
5. **Interactive Spacecraft Platform**: 3D interactive viewport with drag rotation, zoom controls, camera reset, and subsystem hotspots (Navigation Core, Communication Array, Observation Module).
6. **Missions Manifest**: Cinematic timeline with scroll-drawn trajectory line and mission status telemetry (ORBIT-01, ORBIT-02, ORBIT-03).
7. **Earth Observation**: 3D interactive dark globe with atmospheric Rayleigh glow, orbiting satellite, and animated count-up metrics.
8. **Space Data**: Real-time orbital status telemetry with live animated RF sine waveform.
9. **Cinematic Parallax**: Planetary horizon with scroll depth perspective.
10. **About ORBIT**: Mission principles and constellation statistics.
11. **Final CTA & Footer**: Deep-space starfield call-to-action, interactive transmission downlink modal, and system status readout.
12. **Custom Cursor**: Desktop-only dual-ring magnetic cursor with interactive states.
